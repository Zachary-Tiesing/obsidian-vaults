# D&D 5e Obsidian Starter Vault

This starter vault follows the organizational approach from **Obsidian TTRPG Tutorials**:

- `0.DM Screen` — quick-reference rules used at the table.
- `0. Scratch Notes` — temporary notes.
- `1. The Party` — one note per player/character.
- `1. World Almanac` — campaign locations, modules, lore, and world notes.
- `2. Mechanics` — system rules split into linkable categories.
- `2. Session Journals` — one note per session.
- `z_Assets` — images and attachments.
- `z_Templates` — reusable note templates.

## Rules Version

The included rules references are written for **D&D 5e SRD 5.1 / the 2014 ruleset**. They are intentionally concise table references rather than reproductions of the rulebook.

If your campaign uses the **2024 revised 5e rules**, several notes should be updated (especially conditions, exhaustion, hiding, grappling/shoving, surprise, and some action terminology).

## Suggested Obsidian Settings

1. Set `z_Assets` as the default attachment folder.
2. Set `z_Templates` as the Templates core-plugin folder.
3. Turn on **Page Preview** so hovering over Obsidian wikilinks works like a mini rules reference.
4. Optional: install **Kanban** if you want `0.DM Screen/0.DM Screen.md` to behave like a board.
5. Optional: install **ITS Theme** for TTRPG-oriented callout/infobox styling.

## Source / License Note

Rules summaries are based on the Dungeons & Dragons 5th Edition System Reference Document v5.1, published by Wizards of the Coast and available under CC BY 4.0. These notes summarize and reorganize that material for personal campaign reference.
## Character Reference Expansion
This version also includes:
- **319 SRD 5.1 spell catalog notes**, with level and school metadata
- Spell indexes for cantrips through 9th level
- **12 core classes** and their SRD subclasses
- **9 SRD races** and four SRD subraces
- Spell, class, and race templates for future sourcebooks or homebrew

The new material intentionally stays on the **2014 / SRD 5.1** baseline so it remains consistent with the original mechanics pack.
