# Skills

A skill proficiency applies when the DM calls for an ability check where that skill is relevant. The default pairings are:

| Ability | Skills |
|---|---|
| [[Strength]] | [[Athletics]] |
| [[Dexterity]] | [[Acrobatics]], [[Sleight of Hand]], [[Stealth]] |
| [[Intelligence]] | [[Arcana]], [[History]], [[Investigation]], [[Nature]], [[Religion]] |
| [[Wisdom]] | [[Animal Handling]], [[Insight]], [[Medicine]], [[Perception]], [[Survival]] |
| [[Charisma]] | [[Deception]], [[Intimidation]], [[Performance]], [[Persuasion]] |

The DM can pair a skill with a different ability when the situation supports it.
